## Информация для контрибьюторов

Для внесения изменений необходимо:
- установить фреймворк Qt, дополнительно можно скачать Qt Creator или установить необходимые библиотеки в Visual Studio
- Скачать Visual Studio
- Установить все необходимые библиотеки для работы с ASP.NET, если они не подтянутся автоматически
- Адрес бд: localhost://5432


- Внесение изменений
	- Все изменения вносятся в ветку New
- Тестирование
	- Все тесты пишутся в ветке Test
- Главная ветка Main
	- Не вносить никаких изменений
- Новые функции 
	- Ветка Feature
- Подготовка к релизу
	- Ветка PreRelease
- Релиз
	- Ветка Release

## Дополнительно, также для контрибьюторов
- **Необходимо писать документацию к каждой функции**

- **Каждый разработчик при разработке новой функции должен создать новую ветку из ветки Feature. И должен назвать её именем функции и указать свое имя**

- **Все изменения присылать в виде pull request**
